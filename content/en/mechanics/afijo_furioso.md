An Enraged boss starts the fight in phase 2: it uses its phase-2 attacks from the start.

## Effect
- From the start it waits less between attacks, like any boss in phase 2: about 0.67 s instead of 1 s.
- Bosses that Mega Evolve during the fight start already Mega Evolved.
- Mega bosses still reach phase 3, at 35 % health. Other bosses stay in phase 2 for the whole fight.
- It skips the speed boost a boss gets when it changes phase, and [Summoner](afijo_invocador.html) doesn't trigger for phase 2.
- Mewtwo never gets this affix.

All affixes and which bosses get them: [Boss affixes](afijos.html).
