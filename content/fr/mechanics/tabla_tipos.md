## Double type
Contre un Pokémon ou un ennemi à deux types, on regarde les deux colonnes :
- Les deux sont efficaces : ×1,5 × 1,5 = **×2,25**.
- Les deux sont peu efficaces : ×0,67 × 0,67 = **×0,45**.
- L'un efficace, l'autre peu efficace : ils s'annulent, **×1**.
- L'un des deux est neutre : seul l'autre compte.

Exemples : <a class="chip" href="../types/fire.html" style="--c:#ff7a33">Feu</a> contre Insecte + Acier fait ×2,25. <a class="chip" href="../types/electric.html" style="--c:#ffe44d">Électrik</a> contre Eau + Sol fait ×1. <a class="chip" href="../types/fire.html" style="--c:#ff7a33">Feu</a> contre Eau + Sol fait ×0,67.

Si **votre** Pokémon a deux types, ses tirs alternent : un tir du premier type, un tir du second.

## Vos tirs
- C'est le type du tir qui compte, celui de votre Pokémon, contre le ou les types de l'ennemi ou du boss.
- Le multiplicateur s'applique quand le tir touche. Il n'apparaît pas dans votre stat Dégâts du HUD.
- Des flèches au-dessus des ennemis indiquent si vos tirs leur font plus ou moins mal. Avec un double type, la flèche montre la moyenne de vos deux types. Les flèches et les messages « SUPER EFFICACE ! » / « PAS TRÈS EFFICACE » se coupent dans Options > Jeu.

## Les coups que vous recevez
- C'est le type de l'ennemi, de son tir ou de sa zone au sol, contre les types de votre Pokémon.
- Les dégâts se comptent en demi-cœurs. Le jeu arrondit vers le bas et **garde le reste pour le coup suivant** : en moyenne, vous perdez bien ×1,5 ou ×0,67.
- Exemple avec un coup d'un demi-cœur que vous résistez (×0,67) : 0, puis ½, puis ½, puis 0… Quand un coup tombe à 0, vous ne perdez rien : le jeu affiche que vous résistez.
- Exemple avec un coup d'un demi-cœur super efficace (×1,5) : ½ cœur, puis 1 cœur, puis ½, puis 1… Le jeu affiche « ÇA FAIT TRÈS MAL ! ».
