Chaque type est super efficace ou pas très efficace contre d'autres, comme dans les jeux Pokémon (sans immunités : vous infligez toujours des dégâts). Cela vaut pour vos tirs et pour les coups que vous recevez. Table complète : dans Mon équipe, bouton « Table des types ».
