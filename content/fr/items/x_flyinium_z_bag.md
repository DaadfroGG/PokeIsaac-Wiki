Vos tirs de type Vol infligent 30 % de dégâts en plus ; +8 % de chance de coup critique

## Obtention
- On ne le trouve jamais dans les salles au trésor, les boutiques ou les salles de boss. Le seul moyen de l'avoir est de battre un **gardien de zone** de type Vol : le méga-boss du 10e étage de chaque zone de l'[Ultra-Espace infini](../mechanics/zonas_infinito.html).
- Pour l'instant, aucun méga-boss n'est de type Vol : aucun gardien ne peut donner cet objet, il est donc impossible à obtenir.
- Il n'est proposé que si quelqu'un dans l'équipe a un Pokémon de type Vol (banc compris), et seulement si vous avez déjà le [Joyau Vol](x_flying_gem.html) : avant, le gardien propose le Joyau à la place.
- Le gardien laisse trois piédestaux et vous n'en gardez qu'un : les deux autres disparaissent.

## Fonctionnement
- Les +30 % marchent comme ceux du Joyau : appliqués quand un tir de type Vol touche, absents du HUD, non limités par le plafond de ×3. Un Pokémon à double type ne les a que sur ses tirs Vol. Les ticks n'en profitent pas.
- Les +8 % de chance de critique valent pour tous vos tirs, quel que soit leur type. Ils s'ajoutent à vos autres sources de [coups critiques](../mechanics/criticos.html) et à la Chance (+1 % par point).
- Les +30 % se multiplient avec la [Plaque Ciel](x_sky_plate.html) : ×1,3 × 1,15 ≈ ×1,5 sur les tirs Vol.

## Cumul
- Les +30 % sont le même bonus que celui du [Joyau Vol](x_flying_gem.html) : avoir les deux reste ×1,3.
- Les +8 % de critique s'additionnent avec les autres Cristaux Z : deux Cristaux Z de types différents donnent +16 %.
