Vos tirs de type Spectre infligent 30 % de dégâts en plus ; +8 % de chance de coup critique

## Obtention
- On ne le trouve jamais dans les salles au trésor, les boutiques ou les salles de boss. Le seul moyen de l'avoir est de battre un **gardien de zone** de type Spectre : le méga-boss du 10e étage de chaque zone de l'[Ultra-Espace infini](../mechanics/zonas_infinito.html).
- Les gardiens de ce type apparaissent dans le Cimetière Éternel, et parfois dans Le Néant (qui peut amener un gardien de n'importe quel type).
- Il n'est proposé que si quelqu'un dans l'équipe a un Pokémon de type Spectre (banc compris), et seulement si vous avez déjà le [Joyau Spectre](x_ghost_gem.html) : avant, le gardien propose le Joyau à la place.
- Le gardien laisse trois piédestaux et vous n'en gardez qu'un : les deux autres disparaissent.

## Fonctionnement
- Les +30 % marchent comme ceux du Joyau : appliqués quand un tir de type Spectre touche, absents du HUD, non limités par le plafond de ×3. Un Pokémon à double type ne les a que sur ses tirs Spectre. Les ticks n'en profitent pas.
- Les +8 % de chance de critique valent pour tous vos tirs, quel que soit leur type. Ils s'ajoutent à vos autres sources de [coups critiques](../mechanics/criticos.html) et à la Chance (+1 % par point).
- Les +30 % se multiplient avec la [Plaque Fantôme](x_spooky_plate.html) : ×1,3 × 1,15 ≈ ×1,5 sur les tirs Spectre.

## Cumul
- Les +30 % sont le même bonus que celui du [Joyau Spectre](x_ghost_gem.html) : avoir les deux reste ×1,3.
- Les +8 % de critique s'additionnent avec les autres Cristaux Z : deux Cristaux Z de types différents donnent +16 %.
