Vos tirs de type Dragon infligent 30 % de dégâts en plus ; Dégâts +0,3

## Obtention
- On ne le trouve jamais dans les salles au trésor, les boutiques ou les salles de boss. Le seul moyen de l'avoir est de battre un **gardien de zone** de type Dragon : le méga-boss du 10e étage de chaque zone de l'[Ultra-Espace infini](../mechanics/zonas_infinito.html).
- Les gardiens de ce type apparaissent dans le Pilier Céleste, et parfois dans Le Néant (qui peut amener un gardien de n'importe quel type).
- Il n'est proposé que si quelqu'un dans l'équipe a un Pokémon de type Dragon (banc compris). Si vous l'avez déjà, le [Dracozélite](x_dragonium_z_bag.html) prend sa place.
- Le gardien laisse trois piédestaux et vous n'en gardez qu'un : les deux autres disparaissent.

## Fonctionnement
- Les +30 % s'appliquent quand un tir de type Dragon touche : ils n'apparaissent donc pas dans votre stat Dégâts du HUD. Ils ne sont pas limités par le plafond de ×3 des multiplicateurs de dégâts.
- Un Pokémon à double type ne les a que sur ses tirs Dragon, un tir sur deux.
- Les ticks de brûlure et de poison n'ont pas les +30 %.
- Il se multiplie avec la [Plaque Draco](x_draco_plate.html) : ×1,3 × 1,15 ≈ ×1,5 sur les tirs Dragon.
- Le Dégâts +0,3 est un bonus de stat normal : il apparaît dans le HUD et suit les [rendements décroissants](../mechanics/rendimientos.html).

## Cumul
- Il ne se cumule pas avec le [Dracozélite](x_dragonium_z_bag.html) : les deux donnent les mêmes +30 %, les avoir tous les deux reste ×1,3. Le Cristal Z n'ajoute alors que ses coups critiques.
